## Задача 1.2

### Текст задачи

Человек.

Создайте сущность Человек, которая описывается:

- Имя: строка
- Рост: целое число
- Может возвращать текстовое представление вида “Name, рост: height”, где Name и height это переменная с именем и ростом.

Необходимо создать и вывести на экран следующих людей:

- Человек с именем “Клеопатра” и ростом 152
- Человек с именем “Пушкин” и ростом 167
- Человек с именем “Владимир” и ростом 189

### Алгоритм решения

Для решения задачи создан класс `Human`, который хранит два свойства: имя (строка) и рост (целое число). Конструктор принимает оба значения и записывает их в соответствующие свойства.

Текстовое представление возвращает метод `print()`. Он формирует результирующую строку из имени человека, разделителя «, рост: » и значения роста, предварительно преобразованного из числа в строку.

В главной функции создаются три объекта класса `Human` с данными из условия (Клеопатра — 152, Пушкин — 167, Владимир — 189). Для каждого объекта вызывается метод `print()`, а полученная строка выводится на экран.

## Задача 1.3

### Текст задачи

Имена.

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например “Иванов Иван Иванович”). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:

- Клеопатра
- Пушкин Александр Сергеевич
- Маяковский Владимир

Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения

Для решения задачи создан класс `Name` с тремя строковыми свойствами: фамилия, личное имя и отчество. Параметры конструктора имеют значения по умолчанию в виде пустых строк, поэтому любой из них можно не указывать — в этом случае соответствующее свойство остаётся пустым.

Метод `print()` собирает строку по следующему правилу. Результат изначально пуст. Затем по очереди рассматриваются фамилия, личное имя и отчество. Если очередной компонент не пустой, он добавляется к результату; при этом перед ним ставится пробел только в том случае, если в результате уже что-то есть. Пустые компоненты пропускаются, поэтому они не влияют на итоговую строку и не приводят к появлению лишних пробелов в начале, конце или середине.

В главной функции создаются три объекта `Name`, соответствующие именам из условия, и для каждого вызывается метод `print()` с выводом результата на экран.

Человек с именем.

Объедините сущности Человек из задачи 1.2 и Имя из задачи 1.3 таким образом, чтобы имя человека задавалось с использованием сущности 1.3, а не строки.

# Задание 3 и 4

## Задача 3.3

### Текст задачи

Города.

Создайте сущность Город, которая будет представлять собой точку на карте со следующими характеристиками:

- Название города
- Набор путей к следующим городам, где путь представляет собой сочетание Города и стоимости поездки в него.

Кроме того, Город может возвращать текстовое представление, в виде названия города и списка связанных с ним городов (в виде пары: “название:стоимость”).

Используя разработанную сущность реализуйте схему, представленную на рисунке 2 (города A, B, C, D, E, F и пути между ними со стоимостями поездок).

### Алгоритм решения

Для решения задачи создан класс `City`. Город хранит своё название и набор путей. Путь описан вложенной структурой `Path`, состоящей из двух полей: указателя на город-назначение и стоимости поездки (целое число). Набор путей хранится в динамическом массиве (`std::vector`). Для путей используются указатели на существующие города, а не копии, поэтому город-назначение не дублируется, а пути ссылаются на реальные объекты.

Метод `addPath()` принимает город-назначение и стоимость и добавляет новый путь в конец набора путей текущего города.

Метод `print()` формирует строку вида «Название {Город1: стоимость1, Город2: стоимость2, ...}». Сначала в результат записывается название города и открывающая фигурная скобка. Затем выполняется обход всех путей: для каждого пути добавляется название города-назначения, двоеточие и стоимость; между соседними путями ставится запятая с пробелом (перед первым путём разделитель не добавляется). В конце добавляется закрывающая фигурная скобка.

Для реализации схемы с рисунка 2 в главной функции создаются шесть городов (A, B, C, D, E, F), после чего каждому городу добавляются исходящие пути:

- A: в B со стоимостью 5, в F — 1, в D — 6;
- B: в A — 5, в C — 3;
- C: в B — 3, в D — 4;
- D: в A — 6, в C — 4, в E — 2;
- E: в F — 2;
- F: в E — 2, в B — 1.

После этого для каждого города вызывается `print()` и результат выводится на экран.

### Текст задачи

Создаем Города.

Измените сущность Город из задачи 3.3. Новые требования включают:

- Город можно создать указав только название
- Город можно создать указав название и набор связанных с ним городов и стоимостей путей к ним

### Алгоритм решения

В класс `City` из задачи 3.3 добавлена возможность создания объекта двумя способами за счёт двух конструкторов.

Первый конструктор принимает только название города. Он записывает название в соответствующее свойство, а набор путей остаётся пустым; пути в таком случае можно добавить позже методом `addPath()`.

Второй конструктор принимает название города и набор путей (массив структур `Path`, каждая из которых содержит город-назначение и стоимость поездки). Он записывает название и сразу сохраняет переданный набор путей в свойство города.

Остальная логика класса (метод `addPath()` и формирование строки в `print()`) не меняется: пустой набор путей выводится как «Название {}», а заполненный — в виде списка пар «название: стоимость».

# Задание 5

## Задача 5.5

### Текст задачи

Дроби.

Создайте сущность Дробь со следующими особенностями:

- Имеет числитель: целое число
- Имеет знаменатель: целое число
- Дробь может быть создана с указанием числителя и знаменателя
- Может вернуть строковое представление вида “числитель/знаменатель”
- Может выполнять операции сложения, вычитания, умножения и деления с другой Дробью или целым числом. Результатом операции должна быть новая Дробь (таким образом, обе исходные дроби не изменяются)

Затем необходимо выполнить следующие задачи:

1. Создать несколько экземпляров дробей.
2. Написать по одному примеру использования каждого метода.
3. Вывести на экран примеры и результаты их выполнения в формате «1/3 * 2/3 = 2/9»
4. Посчитать f1.sum(f2).div(f3).minus(5)

### Алгоритм решения

Для решения задачи создан класс `Fraction` с двумя целочисленными свойствами: числитель и знаменатель.

Конструктор, принимающий числитель и знаменатель, записывает их в свойства и сразу сокращает дробь: находится наибольший общий делитель модулей числителя и знаменателя по алгоритму Евклида (последовательное деление с остатком), после чего числитель и знаменатель делятся на найденное значение. Если наибольший общий делитель равен нулю, сокращение не выполняется. Дополнительный конструктор, принимающий одно целое число, создаёт дробь с этим числом в качестве числителя и единицей в качестве знаменателя. Благодаря этому конструктору целое число автоматически преобразуется в дробь, и поэтому операции можно выполнять как с другой дробью, так и с целым числом.

Метод `print()` возвращает строку «числитель/знаменатель». Если знаменатель равен единице, выводится только числитель (например, целое число 5 выводится как «5», а не «5/1»).

Арифметические операции реализованы перегруженными операторами `+`, `-`, `*` и `/`, каждый из которых принимает две дроби и возвращает новую дробь, не изменяя исходные:

- сложение и вычитание приводят дроби к общему знаменателю перекрёстным умножением: числитель результата равен сумме (разности) произведений числителя каждой дроби на знаменатель другой, знаменатель результата — произведению знаменателей;
- умножение перемножает числители и знаменатели между собой;
- деление умножает первую дробь на перевёрнутую вторую, то есть числитель результата равен произведению числителя первой дроби на знаменатель второй, а знаменатель — произведению знаменателя первой на числитель второй.

Результат каждой операции создаётся через конструктор с двумя параметрами, поэтому итоговая дробь автоматически сокращается.

В главной функции три дроби вводятся пользователем. Для них вычисляются сумма, разность, произведение и частное, а результаты выводятся в формате «f1 знак f2 знак f3 = результат». Выражение из пункта 4 задачи (сложить первую и вторую дроби, разделить результат на третью, вычесть 5) считается как ((f1 + f2) / f3) − 5, где целое число 5 неявно преобразуется в дробь 5/1, и выводится на экран.
